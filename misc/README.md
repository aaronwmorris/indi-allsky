# Overview

Information about these scripts may be found in the wiki.

https://github.com/aaronwmorris/indi-allsky/wiki/Misc-Folder

`asi676mc_frame_repair.py` is a self-contained RAW16 RGGB detector, repairer,
and folder calibration tool for the ASI676MC purple-frame failure. Calibration
writes a text report with the exact Image-settings labels for manual entry; it
does not read or write installation configuration files. Detailed usage,
evidence requirements, and safety checks are recorded in
`docs/asi676mc-frame-repair.md`.
