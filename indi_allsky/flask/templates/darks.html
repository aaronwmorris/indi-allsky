How was this decided? Technical details
How the recommended grid is built

The builder reads the relevant saved day, night, moon and SQM capture profiles. For each distinct image profile, it combines the camera strategy's gain values with exposure lengths stepped down from {{ "%g"|format(dark_execution_preview.exposure_max) }} seconds by {{ "%g"|format(dark_execution_preview.exposure_step) }} seconds; 1 second is always included. Duplicate combinations shared by several capture profiles count only once.

This produces {{ dark_analysis.target_count }} recommended master set{% if dark_analysis.target_count != 1 %}s{% endif %}. Each needs both a compatible master dark and bad-pixel map. The builder then checks every set against the stored library and the temperature rule to decide what should be captured now. Stored files outside the recommendation remain in the library and are not counted below.

A stored set can fall outside today’s recommendation when the current capture configuration no longer asks for that exact image profile, gain or exposure—for example after changing a capture profile, gain strategy, longest exposure or exposure interval. This does not mean the stored set is damaged; it is simply not needed by the current recommended grid.
