How the recommended grid is built

The builder reads the saved day, night, moon and SQM profiles from Config → Camera. For each unique image profile, it combines the required gains with exposures from {{ "%g"|format(dark_execution_preview.exposure_max) }} seconds down in {{ "%g"|format(dark_execution_preview.exposure_step) }}-second steps. One second is always included, and duplicate combinations count once.

This produces {{ dark_analysis.target_count }} recommended master set{% if dark_analysis.target_count != 1 %}s{% endif %}. Each needs a compatible dark and map. The builder checks the library and temperature rule to decide what to capture. Other stored files stay untouched.

A stored set may fall outside today’s recommendation after Config → Camera settings change. It is not damaged; the current profiles simply do not need it.
