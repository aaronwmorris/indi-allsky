{{ form_config.IMAGE_DENOISE.label(class='col-form-label') }}
{{ form_config.IMAGE_DENOISE(class='form-select bg-secondary') }}
Note Denoising adds processing time - concern if only a short time limit set between exposures.
Algorithm to reduce image noise (applied before stretch). Methods respect stars. Default for all: 3
Methods operate at similar speed. Except for Wavelet Filter- slowest, but best quality.
  • Gaussian Blur — Targets noise with gentle, uniform smoothing.
  • Median Blur — Best for removing salt-and-pepper noise. Outlier pixels replaced by median of neighbors.
  • Bilateral Filter — Edge-aware filter. Smooths sky noise while preserving star edges.
  • Wavelet Filter — Removes noise at all scales. Best for read noise and faint sky noise. Slowest, best quality.
Warning Not supported on Debian 11 (bullseye) or Ubuntu 20.04 (focal) and older
