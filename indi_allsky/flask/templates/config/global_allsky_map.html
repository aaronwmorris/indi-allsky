Global Allsky Map — AllskyTeam

This is the Allsky project's public map, separate from allsky-map.com.

Publication shares the coordinates shown in Preview, location, owner, camera, lens, computer, equipment, public URLs and INDI-AllSky version. Location accuracy controls public coordinate detail; global Privacy Mode always uses whole degrees. Public images/text can still identify your location.

No image bytes, host machine ID or INDI-AllSky configuration are uploaded. A random persistent installation identifier is sent as the map record key; it is not authentication or an API key.

Global Privacy Mode is enabled. Global Map uses whole-degree coordinates; this setting has no effect.

Limits public location detail; cannot improve your configured/GPS location accuracy. Exact uses the saved location and can reveal your home/site. Grid output is limited by source precision; approximate grid spacing is not a guaranteed error or anonymity radius. Save, then Preview the coordinates that will be published.

Turning Privacy Mode off reactivates the saved accuracy choice, including Exact. Registered metadata changes may publish automatically; coarser settings do not erase previously published locations.

Optional shared public website address. Both URLs may be empty; an image alone is valid. A website requires an image URL, but they may use different domains. Public URLs must not require a login.

Location, owner and lens reuse their existing Config settings; camera/computer/version are automatic. Save changes first, then Preview the saved metadata. Preview stores an installation identifier locally but sends nothing. First registration always requires Register.

Once registered and enabled, changes to the shared Owner, Location, coordinates, Lens or Privacy Mode settings are published automatically.

Registered, enabled installations refresh about every 48 hours and after metadata changes. Ordinary publication is limited to five attempts in a rolling 24 hours; Remove does not use this local budget. Force is a deliberate server-quota override, never automatic. Failures with unknown outcomes need manual review, not automatic retry.

Disabling stops future publication but does not remove an existing listing. Remove and disable saves Disable immediately and queues removal; if removal fails, publication stays disabled. Re-enabling never changes the installation identifier.
