Derive purple-frame repair values from FITS saved by indi-allsky or from a collection you select manually.
How it works
Let indi-allsky search its saved FITS, or select a complete FITS collection from your device. Both methods perform the same checks and produce the same calibration values. Uploaded copies remain private and are deleted when the run ends.
Evidence needed
Use daylight data with visible highlights and at least two exposure levels. Calibration needs at least seven purple frames and seven different compatible normal frames; before-and-after references are better. If files are skipped or the run stops, the result or failure message explains what to check.
Current FITS capture settings

These settings affect future captures only. Existing data can still be used: saved FITS search works with previously flagged purple frames, while manual upload identifies them from the selected files. Both camera-bound paths can use legacy standard FITS with a generic camera name, but RAW16, RGGB, 1x1 binning, zero Bayer offsets, valid capture metadata, and matching frame dimensions within each evidence group are still required.
