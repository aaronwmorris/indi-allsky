# Overview
The mini-timelapse functionality in indi-allsky is meant to create a timelapse video to highlight an event.  For instance, a meteor or an object appearing in view.

## Accessing the Interface
In order to generate a mini-timelapse, navigate to the Media -> Images view.  Find the image with the event you want to highlight.  Under the image, click the `Mini Timelapse` button.

## Generate
* Select the amount of time prior to the image you want to include in the timelapse
* Select the amount of time after the image to include
* Choose the frame rate of the timelapse.
    * A low FPS will result in a longer, but slower timelapse
* Enter a description for the timelapse
* Click `Create`
* After a few minutes, the mini-timelapse should become available in the Mini-Timelapse view
